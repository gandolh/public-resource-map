**Public Resource Map** is a place-centric web app for Romanian cities. The
map's unit is a **place** — a park, library, clinic, museum or town hall — and
events attach to places. You pick a city, see what is near you, select a place,
and see what is on there.

:::caution[It is a proof of concept, and that is a legal position, not modesty]
The tech is demonstrable end to end. **Commercial or public launch of any
reuse-restricted source is blocked on obtaining permission.** OSM data is ODbL
and reuse-permitted — that is why it is the clean anchor. Event data comes from
public primary publishers, API-first and scrape-last, and never from a ticketing
aggregator. See [Decisions → Legal posture](/wiki/decisions/).
:::

## The one-line data model

Pins are **places**, from two sources:

- **OSM** — parks, libraries, clinics, museums, town halls. ODbL, reuse
  permitted, the clean anchor.
- **event-venue** — created only when an event's venue cannot be matched to an
  OSM place.

Events attach to places. A buy-tickets link appears **only when the public
source itself provides one**.

## Why the map is place-centric

The code was originally **event-centric** — a `/map` of resource markers, a
standalone `/events` grid, and `/resources/:id` — and the 2026-06-28 grilling
session re-shaped the product around places instead.

That pivot is the single most load-bearing thing to understand before changing
anything: a place is the durable object, and an event is something that happens
at one. Parts of the code still predate it. [Status](/wiki/status/) is honest
about which.

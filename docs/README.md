# Public Resource Map docs

Start with the [main README](../README.md). This folder does two jobs: it is the Docusaurus docs site deployed at `/prm/docs/`, and it holds the files the README links to. The site build ignores this file, `getting-started.md` and `images/`.

| Path | What it covers |
|---|---|
| [getting-started.md](getting-started.md) | Full local setup: env vars, seed, sign-in, the admin, tests, building this site |
| [images/](images/shots.md) | The screenshots, GIF and diagram in the README, and how each was made |
| [docs/](docs/) | The site's own pages: [what PRM is](docs/index.mdx), [HTTP API](docs/api.mdx), [data model](docs/data.mdx), [ingestion](docs/ingestion.mdx) |
| [diagrams/](diagrams/) | archify sources for the site's two diagrams, `architecture.json` and `ingestion.json` |
| [static/diagrams/](static/diagrams/) | The compiled diagram pages, committed so the site builds on a machine without archify |
| [scripts/](scripts/) | `sync-corpus.mjs` copies `corpus/wiki/` into the site; `build-diagrams.mjs` compiles the diagrams |

The rest is the site's own configuration: `docusaurus.config.ts` with the `/prm/docs/` base path and both colour modes, `sidebars.ts` with the sidebar, `package.json`, `tsconfig.json`, `typedoc.json`, the diagram embed in `src/components/` and the theme in `src/css/`.

Each build regenerates three gitignored folders. `docs/wiki/` is copied from `corpus/wiki/`, `static/reference/` is TypeDoc over `shared/`, and `dist/` is the built site, with Docusaurus's cache in `.docusaurus/`. Build the site with `npm run docs -w docs` from the repo root.
